# Game Environments

A game environment is the combined setting that can create fantasy volume: scoring expectation, pace, opponent response, and concentrated roles. Good environments can supply connected outcomes for tournament lineups.

## Build a game note

Record the total, spread, likely scoring paths, and players who benefit if the game stays competitive. Then identify the condition that would make the environment fail, such as a slow pace or an offense with dispersed touches. This prevents a high total from becoming an automatic stack.

## Choose correlation intentionally

A quarterback and pass catcher often benefit from the same scoring event. An opponent can be useful when its production encourages continued passing. Use that relationship only when each player has a reasonable role and price.
