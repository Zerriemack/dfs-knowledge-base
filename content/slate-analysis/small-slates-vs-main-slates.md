# Small Slates vs. Main Slates

Slate size changes the player pool and the way lineups overlap. A construction that is unusual on a large slate can be common when only a few games are available.

## Small slates

Small slates concentrate ownership around a limited set of strong roles. Fades carry more risk because there are fewer substitutes. Consider game script and roster combinations rather than expecting every player to be unique.

## Main slates

Main slates offer more salary paths, value choices, and game environments. The broader pool can create more viable pivots, but it also increases the research needed to separate strong alternatives from thin plays.
