# Three-Max Strategy

Three-max contests allow a small portfolio without requiring the breadth of mass entry. Each lineup should represent a distinct but defensible read rather than three near-copies.

## Define the portfolio

Set the maximum exposure to a quarterback, game, or value play before building. Then assign each lineup a different condition: one may favor a popular game with a less common secondary player, while another tests a different game environment. Shared players are acceptable when their role is strong.

## Check overlap

Compare the three lineups side by side. High overlap is not automatically wrong, but it means the portfolio depends heavily on one slate outcome. Replace a player only if the change creates a meaningful alternate path, not because every lineup must look unrelated.

| Review item | Useful question |
| --- | --- |
| Game exposure | Which environments can carry the portfolio? |
| Player overlap | What result harms all three lineups? |
| Salary pattern | Are the entries duplicated by construction? |
