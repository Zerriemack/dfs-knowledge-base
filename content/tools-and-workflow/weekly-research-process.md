# Weekly Research Process

A weekly process gives each slate the same basic sequence while leaving room for late information. It reduces the chance that a compelling narrative replaces role, price, and contest context.

## Build the slate file

Begin with a schedule, salaries, injury watch list, and early player roles. Use historical data sources such as [[org-system-analysis|Pro Football Reference]] for context when needed, then write a short note on each game environment. Keep the notes conditional when information is incomplete.

## Move from research to entry

Update player roles when official news arrives. Select the contest, create a player pool, and build lineups with salary and correlation rules. Before lock, use [[tools-and-workflow/lineup-review|Lineup Review]]. After the slate, record the decisions in [[tools-and-workflow/tracking-results|Tracking Results]].
