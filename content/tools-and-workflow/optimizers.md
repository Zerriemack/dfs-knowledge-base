# Optimizers

An optimizer searches combinations under salary and roster rules. It is useful for comparing a defined player pool, but its output is only as reliable as the inputs and constraints.

## Set the inputs

Review projections, player eligibility, exposures, stacking rules, and minimum salary before generating lineups. A missing injury update or an unrestricted weak player can produce output that looks efficient while contradicting the slate read.

## Inspect, then edit

Read the top lineups for duplicated construction, unsupported players, and missing correlation. In a portfolio, inspect exposures across all entries rather than accepting the first group of lineups. Manual review is where contest objectives meet the generated output.
